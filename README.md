# Votação A Fazenda 2026

Aplicação React para votar em quem deve deixar a roça e acompanhar a parcial da votação. Os votos são armazenados no navegador usando `localStorage`.

## Executar

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite. Para gerar a versão de produção, execute `npm run build`.

## Funcionalidades

- Página inicial com o fazendeiro e os participantes da roça.
- Votação ilimitada nos três participantes da roça, com confirmação de cada voto.
- Resultado ordenado por votos, com percentuais e opção para zerar a contagem.
- Fotos e fontes locais fornecidas com o projeto, sem dependência de internet.
